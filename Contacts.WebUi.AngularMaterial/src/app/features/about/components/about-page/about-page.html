Welcome to Contacts Demo app

This is a small demo app created with Angular Material and .Net Web API. It demonstrates CRUD functionality along with list paging, sorting and filtering.

Please see README in the source code repository for details.

Note: all API endpoints have artificial half a second delay for the sake of demoing the frontend's loading states. Plus the first time you go to the Contacts route it may take a few seconds to load as Azure App Service spins up the API.
